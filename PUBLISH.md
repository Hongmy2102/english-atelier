# Trạng thái đưa lên GitHub

Đã tạo repository cục bộ riêng, nhánh main, và đẩy mã nguồn lên https://github.com/Hongmy2102/english-atelier sau khi chủ tài khoản tạo repository rỗng. Commit mã nguồn đầu tiên: 52bce7b. Trang Deutsch được giữ nguyên.

Chưa xác nhận GitHub Pages được bật hoặc website đã online. GitHub API vẫn chưa truy cập được trong môi trường này.

## Bật GitHub Pages trong trình duyệt

1. Mở https://github.com/Hongmy2102/english-atelier/settings/pages.
2. Trong Build and deployment, chọn Source: Deploy from a branch.
3. Chọn nhánh main và thư mục / (root), rồi Save.
4. Chờ GitHub build; xem kết quả trong Actions hoặc Settings → Pages.
5. Kiểm tra địa chỉ dự kiến https://hongmy2102.github.io/english-atelier/ trước khi xác nhận website đã hoạt động.

Các bước bật Pages nêu trên chưa được thực hiện tự động hoặc xác minh. Nếu GitHub hiển thị tùy chọn khác, kiểm tra trạng thái hiện tại trước khi thay đổi.
